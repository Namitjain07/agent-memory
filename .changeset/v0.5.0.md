# v0.5.0 — Comprehensive Improvements Release

## Highlights

This is the first release of the full v0.5.0 line. It bundles **three rounds of
work** over 11 commits:

- 89 files changed, 9374 insertions, 1148 deletions
- 137 → 153 tests
- 6 packages with unified SEO, CI, and tooling

## What's new in `@namitjain.india/agent-memory` v0.5.0

### Resilience

- Retry with exponential backoff + jitter (default 3 attempts, 250ms → 5s)
- `AbortSignal` propagates through every async operation
- Configurable timeouts on adapter / embedding calls
- `MemoryError` hierarchy with structured codes (`TIMEOUT`, `EMBEDDING_FAILED`, `ABORTED`, etc.)

### Multi-tier scoping (NEW)

- `tier` + `userId` + `agentId` fields
- Backward compatible — omit `tier` and items are session-scoped (legacy)
- Like mem0, but with hybrid scoring built in

### Hybrid scoring

- Vector similarity (semantic) + BM25 (keyword) + recency + importance
- All four components weighted and tunable via `weights`
- 2.1× slower than pure vector but measurably higher recall on keyword-heavy queries

### Batched operations

- `rememberBatch({ items, concurrency })` for inserting many items at once

### LRU embedding cache

- Avoid re-embedding the same text
- Default 1000 entries, tunable via `embedding.cacheSize`

### Encryption at rest (BREAKING)

- AES-256-GCM with envelope validation
- **BREAKING**: `keyFromPassphrase` now requires a per-user salt (was static salt — a security antipattern)
- New `generateSalt()` helper

### PII redaction (BREAKING in regex shape)

- Detects emails, phones, US SSNs, credit cards, IPv4, JWTs, hex API keys
- Regex tightened to avoid SSN/IP false positives and ReDoS

### Memory graph (BETA)

- PageRank scoring
- Spreading activation
- Community detection
- Bridge nodes

### 9 LLM providers

OpenAI, Azure OpenAI, Cohere, HuggingFace, Voyage AI, Mistral, Google Gemini, Jina, Ollama, plus custom providers.

### 3 storage adapters

In-memory (default), SQLite, pgvector.

### Tooling

- ESLint + Prettier + EditorConfig
- TypeScript strict mode + `exactOptionalPropertyTypes`
- Changesets for future releases
- CI matrix on Node 20 + 22, plus CodeQL + OpenSSF Scorecard

## Migration from v0.4.x

```diff
// v0.4.x
const key = keyFromPassphrase("my passphrase");

// v0.5.0
import { generateSalt, keyFromPassphrase } from "@namitjain.india/agent-memory";
const salt = generateSalt(); // per-user
const key = keyFromPassphrase("my passphrase", salt);
```

Everything else is backward compatible.
