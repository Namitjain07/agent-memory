# Security Policy

## Supported Versions

Security updates are provided for the latest published major/minor line.

| Version | Supported |
| --- | --- |
| 0.x (latest) | Yes |
| Older prereleases | No |

## Reporting a Vulnerability

Please report vulnerabilities privately:

1. Open a GitHub Security Advisory (preferred):  
   https://github.com/Namitjain07/agent/security/advisories/new
2. If advisory flow is unavailable, open a private report to the maintainer.

Please include:

- affected package(s) and version(s)
- reproduction steps or proof of concept
- impact assessment
- suggested remediation (if available)

We will acknowledge reports promptly and work on a fix before public disclosure.
